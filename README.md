# kNN Iris Classifier (Java)

This project implements the k-Nearest Neighbors (kNN) algorithm from scratch in Java using the Iris dataset.

## Features
- Loading data from a text file (iris.txt)
- Train/test split (e.g. 80/20)
- Euclidean distance calculation
- kNN classification
- Accuracy evaluation
- Manual input for custom test vectors

## How it works
The algorithm calculates the distance between a test vector and all training vectors, selects the k nearest neighbors, and assigns the most frequent class among them.

## Usage
1. Run the program
2. Choose k (number of neighbors)
3. Select:
   - accuracy test
   - manual input

## Technologies
- Java
- No external libraries
